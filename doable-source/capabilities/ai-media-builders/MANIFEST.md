# AI Media / Document Builder Servers

Immutable Doable source: `doable-source/mcp-servers/image-generator/`, `markdown-builder/`, `pdf-builder/`, `presentation-builder/`, and `spreadsheet-builder/`, plus `mcp-servers/_shared/`.

These are complete optional MCP capabilities for AI-generated images and document artifacts: Markdown, PDF, PowerPoint/web slides, and spreadsheets. Preserve their package manifests, skills/instructions, worker/engine code, and MCP transport behavior together.

Host boundaries: provider credentials, artifact/object storage, execution limits, MCP registration, UI/theme.
