# APCP — Fresh Chat Continuation Check

Use this checklist before implementation in a new conversation.

- [ ] Repository instructions read.
- [ ] CHAT_CONTINUITY read.
- [ ] NEXT_ACTION read and is singular.
- [ ] CURRENT_PHASE and PROJECT_STATE read.
- [ ] Plan and active decisions read.
- [ ] Git branch and HEAD reconciled.
- [ ] Authorized scope identified.
- [ ] Acceptance criteria identified.
- [ ] Verification state distinguished from implementation state.
- [ ] Open blockers, issues and risks identified.
- [ ] No stale or pending evidence is being treated as PASS.
- [ ] No future phase is being started without authorization.
