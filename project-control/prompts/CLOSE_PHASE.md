# APCP — Close Phase

Phase closure is governance, not an implementation side effect.

Before closure: map every acceptance criterion to current evidence; run required verification; resolve or explicitly owner-accept Critical and Important findings; reconcile scope; record follow-ups; identify Git state; ensure control files agree; obtain explicit closure authority.

Then record phase status, evidence, unresolved follow-ups, closure commit, next phase and exceptions.

Passing tests alone never closes a phase.
