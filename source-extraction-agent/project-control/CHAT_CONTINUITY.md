# Chat continuity

## Mission
Build and maintain a reusable agent system for discovering, extracting and verifying exact first-party source from upstream repositories.

## Source of truth
The Git repository, pinned source commit/tree, manifests, evidence artifacts and project-control records outrank conversational summaries.

## Current checkpoint
Initial authoring branch: feature/source-extraction-agent.
This package defines rules, prompts, skills, workflows, templates and schemas. Do not claim executable verification or extraction of upstream code until performed and evidenced.

## Resume procedure
Read AGENTS.md, EXTRACTION_RULES.md, EXTRACTION_AGENT_SPEC.md, then this folder's project-control files and latest WORKLOG entry. Inspect actual branch/commit and existing files. Continue NEXT_ACTION.

## Handoff contract
Every session records changed files, commits, actual checks, pending features, awaited evidence, blockers, and one next action. Preserve chronological history and do not repeat completed work.
