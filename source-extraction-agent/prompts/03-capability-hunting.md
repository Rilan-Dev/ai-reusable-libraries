# Prompt 03 — Capability hunting

Discover reusable capabilities by behavior, not just directory or naming conventions. Search entry points, symbols, routes, event names, schema names, package boundaries, tests, UI navigation and runtime registrations.

Inspect AI and non-AI enablers including validation, permissions, workflow engines, state machines, media, attachments, search, caching, observability, audit, quotas, billing boundaries, templates, collaboration, versioning, import/export, CLI, sandbox, browser automation, scheduling, notifications and recovery.

For each candidate use templates/capability-manifest.md. Record Tier, disposition, exact paths, callers, callees, persistence, external dependencies, UI states, tests and confidence/evidence. Never count a keyword hit as proof a feature is implemented.
