# Prompt 08 — Independent second-pass audit

Ignore the comfort of the first inventory. Re-scan the complete pinned repository with independent methods: route and symbol search, dependency graph, manifests, migrations, UI route trees, tests, workflows, event registrations, plugin/skill catalogs, CLI commands, runtime configuration and documentation.

Search for hidden or indirectly named features: websocket/SSE protocols, real-time events, attachment/media pipelines, planning/evaluation, feedback, browser/runtime, collaboration, templates, version control, backup/restore, usage/cost/quota, tracing/audit, memory/RAG/search/cache, webhooks, notifications, MCP/A2A, subprocess/native tools and remote agents.

Every candidate gets one explicit disposition: already captured, reusable Tier 1, reusable Tier 2, dependency closure, UI reference, host boundary, product-only, or not applicable with evidence. Reconcile counts and IDs against the first inventory. Do not duplicate already pinned trees.
