# Skill: Repository Intelligence

Establish trustworthy source identity and recover existing work. Inspect refs, commits, root tree, repository guidance, package/workspace layout, license/NOTICE, submodules, LFS, manifests, lockfiles, CI and project-control. Distinguish requested ref from default branch. Record exact paths and provenance. If access is incomplete, stop destructive work and record the specific missing evidence. Never guess a branch head or file tree.
