# Skill: Capability Discovery

Find capabilities through entry points, call graphs, routes, event handlers, CLI commands, registries, tests, migrations and UI navigation—not only names. Build a stable candidate registry and deduplicate aliases to the same implementation. For each capability record purpose, public interface, source paths, caller/callee chain, dependencies, tests, persistence, UI surfaces, tier and evidence. A README claim or keyword hit is a lead, not proof of implemented behavior.
