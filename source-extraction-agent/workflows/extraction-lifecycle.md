# Extraction lifecycle

1. Recover: inspect existing project-control and working tree.
2. Onboard: verify repository/ref/license and pin commit/tree.
3. Map: architecture, execution paths, data and UI.
4. Inventory: enumerate capabilities and business rules.
5. Close: resolve static/dynamic/runtime/data/test/package dependencies.
6. Reconcile: independent full-repository second pass.
7. Gate: document explicit scope/closure PASS.
8. Capture: exact immutable source and UI references.
9. Package: contracts, adapters, capability manifests, external inventory.
10. Verify: machine-check source integrity and inventory consistency.
11. Publish: copy-to-any-project instructions and gap report.
12. Handoff: update durable project-control records.
